# Changelog

## 1.0.0 (unreleased)

First open-source release.

- 38 algorithms in 13 categories and a 7-track learning path, each step explained in English and Hindi.
- Viewer with gliding items, playback at 7 speeds, scrubbing, keyboard shortcuts, legend and watch chips.
- Code panel: pseudocode, Python, Java, C++ and JavaScript with the current line highlighted; every snippet is tested in its own language.
- Input panel with validation for every input type, random inputs, and a pathfinding grid editor.
- Predict-the-next-step quiz, narration, classroom mode, dark mode, share links to an exact step, and PNG export.
- Pre-rendered pages in English and Hindi for every algorithm and track, readable without JavaScript, with structured data and a sitemap.
- Installable; works offline after the first visit.
- No backend, no tracking, no requests to other sites.
