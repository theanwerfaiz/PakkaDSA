# Roadmap and starter issues

Ideas for contributors, ready to be opened as issues. Small ones are marked **good first issue**.

## New algorithms (label: `new-algorithm`)

Each follows [ADDING_AN_ALGORITHM.md](ADDING_AN_ALGORITHM.md).

- Counting sort · Shell sort (**good first issue**)
- Jump search · Exponential search (**good first issue**)
- Prefix sums (**good first issue**) · Three-sum (two pointers)
- Sliding window maximum (monotonic deque)
- Merge two sorted lists (**good first issue**)
- Union-find · Kruskal's MST · Prim's MST
- Bellman–Ford · Floyd–Warshall
- Trie insert and search · LRU cache (conceptual)
- Edit distance · Longest increasing subsequence · Rod cutting · Subset sum
- Sudoku solver (backtracking) · Permutations · Word search

## New code languages (label: `new-code-language`)

Go · Rust · C# · Kotlin · TypeScript

## Translations (label: `translation`)

- Native-speaker review of the Hindi text (UI strings, the 7 track descriptions, and step messages)
- Bengali · Tamil · Telugu · Marathi · Gujarati · Urdu (needs right-to-left layout)

## Features (label: `enhancement`)

- Compare mode: two algorithms on the same input with a shared step counter
- Editable graph for BFS, DFS, Dijkstra and topological sort
- GIF or WebM export of a run
- More quiz questions for algorithms that have none (merge sort, graphs, DP)
- Smaller Devanagari handwriting font (subset Kalam) for faster Hindi pages

## Quality (labels: `accessibility`, `bug`)

- Accessibility review by a screen-reader user
- Reports from real devices, especially low-end Android phones
